# School register in C:
C program that manages a student register using a linked list.


## Allowed operations:

- Add students in alphabetical order.

- Add Italian literature and History grades (up to 8 per subject).

- Delete a student from the register.

- Print only the list of students names.

- Print the list of grades for a student.

- Print a table with students and grades, i.e. the register itself.


## Files:

- studenttest.c : test file/ main program and interactive menu.

- student.c : implementation of the linked-list operations.

- student.h : function declarations.

- studenttest.exe : program.


## Compilation:

Compile the program using GCC:

\begin{verbatim}
gcc -Wall -Wextra -std=c11 studenttest.c student.c -o studenttest
\end{verbatim}


## Execution:

On Windows PowerShell:

\begin{verbatim}
.\studenttest.exe
\end{verbatim}
